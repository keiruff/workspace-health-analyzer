# Workspace Health Analyzer

Workspace Health Analyzer is a PowerShell utility designed to help CAD Managers, ProjectWise Administrators, and Engineering Technology teams identify workspace configuration issues, standards drift, and workspace integrity problems.

---

## Are You Trying to Figure Out...

* Why users suddenly started experiencing workspace errors?
* Which configuration files changed before problems began?
* Whether DGNLIB files were modified unexpectedly?
* Which workspace resources are missing?
* Whether a workspace differs from an expected baseline?
* Why some users can open files while others cannot?

---

## Common Workspace Problems

Engineering organizations often struggle with:

* Corrupted user preferences
* Missing workspace resources
* DGNLIB inconsistencies
* Configuration drift
* Workspace version mismatches
* CAD standards deviations

---

## Planned Features

### Configuration Inventory

Identify:

* CFG files
* PCF files
* UCF files

### Standards Inventory

Identify:

* DGNLIB files
* CEL files
* RSC files

### Change Tracking

Report:

* Modified files
* File dates
* Added resources
* Missing resources

### Workspace Integrity Checks

Detect:

* Missing standards files
* Empty resource folders
* Unexpected configuration changes
